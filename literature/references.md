# Literature Reference Index

This index catalogs all sources retrieved during the initial literature survey for ML-based geodetic coordinate transformations. Sources are tagged by relevance category:
- **`[CAT-1]`**: Closely related (stereographic projections, distortion/shift grids, residual grid modeling).
- **`[CAT-2]`**: Broader ML coordinate transformation literature (MLP, RBFN, ELM, SVR/LS-SVM, GP/Kriging, PINNs, GeodesyNets).
